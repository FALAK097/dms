## Design Context

### Users

Legal & property professionals (lawyers, conveyancers, agents) managing case
files, deeds, contracts, and agreements. They work with high-stakes PDFs where
a wrong answer costs money — they need to trust every response and trace it
back to the source document. Context: desk work, reviewing files, preparing
filings; often returning to the same library repeatedly.

### Brand Personality

Calm, precise, trustworthy. The interface should feel like a well-kept deed
room: quiet, ordered, everything labelled and findable. No hype, no urgency
theatre — confidence through precision.

### Aesthetic Direction

- Visual tone: refined minimal with an archival-document character. Serif
  display type (the visual language of printed deeds) paired with the existing
  Outfit product UI font. Paper-like tinted neutrals, ink text, mint-green
  brand accent, one restrained gold reserved for citation/verified moments.
- Theme: must look excellent in both light and dark mode (the app ships a
  theme toggle). Dark = deep pine-tinted surfaces, never pure black.
- Anti-references: gradient headline text, purple/blue AI gradients,
  glassmorphism, icon-in-rounded-square grids, side-stripe accent borders,
  centered-only layouts.
- Hero strategy: show, don't tell — an interactive-feeling mini demo of the
  core value (ask a question, get a cited answer from a real-looking
  document) instead of abstract claims.

### Design Principles

1. **Cite everything**: every claim the product makes should be traceable to
   a source, in the UI as in the copy.
2. **Restraint signals trust**: fewer colors, fewer sizes, more whitespace.
   Accents are rare on purpose.
3. **Speak the user's visual language**: deeds are serif, indexed, stamped —
   borrow that archival precision instead of generic SaaS chrome.
4. **Motion means state**: animate only entrances, reveals, and feedback;
   exponential easing, transform/opacity only, always honor reduced motion.
5. **Both themes are first-class**: every new surface is designed in light
   and dark together, never adapted after the fact.
